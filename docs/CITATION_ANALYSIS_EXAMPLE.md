# Analysis-Specific Citation Example

Use this for study-specific repositories created from the template.

## What To Do

1. Copy `docs/CITATION_ANALYSIS_EXAMPLE.cff` to `CITATION.cff` in your study repo.
2. Replace all bracketed placeholder values.
3. Update `version` and `date-released` at each release.
4. Keep the template citation in `references` so provenance is explicit.

## Example Methods Text For Study Repo

"Study-specific analysis code is available at [STUDY_REPO_URL] and cited using the
repository `CITATION.cff` metadata (version [VERSION])."

## Optional Extended Methods Text

"Study-specific analysis code was derived from the OMOP Study Template and adapted
for [STUDY_NAME]. The analysis repository is archived at [STUDY_REPO_URL]
(version [VERSION], released [DATE])."
