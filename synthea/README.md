# synthea/

Synthea disease module and generated artifacts for OMOP observational studies
using the synthea-omop-template template repository.

## modules/

| File | Description |
|------|-------------|
| `study_template.json` | Generic Synthea state-machine module. Copy and rename this file for each new study, then fill in all `REPLACE_ME` concept codes and tune all `RESEARCHER_ADJUSTS` numeric values. See **Customisation checklist** below. |
| `study_template.diagram.html` | Auto-generated Mermaid state-diagram of `study_template.json`. Regenerated by `workflow/03_generate_synthea_module_artifacts.R`. Open in any browser to review module logic visually before SME sign-off. |

A worked example of a customised module (PAD open-revascularization with SSI
outcomes) is in the `pad-oler-ssi-val` study repository.

## Clinical pathway overview

The template simulates a generic surgical or procedural study pathway:

1. **Eligibility** — age guard (min/max) and onset delay
2. **Exposure condition** — qualifying diagnosis that leads to the index encounter
3. **Outpatient evaluation** — comorbidities (covariates 1–4) documented
4. **Treatment strategy** — oversampling branch (non-exposed vs. target-exposed)
5. **Pre-procedure workup** — delay from diagnosis to index event
6. **Index procedure** — inpatient encounter + procedure
7. **Post-discharge observation** — window aligned with `prediction_window_days`
8. **Outcome assessment** — fixed-probability gate (tunable incidence)
9. **Outcome management** — encounter, treatment, resolution

## Customisation checklist

Work through these eight items before running Step 4 (Synthea data generation):

1. **Age range** — set `Age_Guard` quantity (minimum age) and `Age_Cap_Check`
   quantity (maximum age) to match your study population.

2. **Exposure condition** (`Exposure_Condition_Onset`) — replace `REPLACE_ME`
   with the SNOMED-CT code for the qualifying diagnosis. Run:
   ```
   Rscript scripts/concept_lookup.R "<condition name>" Condition
   ```

3. **Covariate 1** (`Covariate_1_Check` / `Covariate_1_Onset`) — set the
   distribution to the prevalence of `covariate_1` in your population; replace
   `REPLACE_ME` with the concept code matching `covariate_concepts.csv` row
   `covariate_1`.

4. **Covariates 2–4** — repeat step 3 for `Covariate_2` through `Covariate_4`.
   Note: `covariate_2` domain is `procedure` and `covariate_3` domain is `drug`
   in the default `covariates.csv` — change the state type accordingly.
   `covariate_4` also requires a new row in `covariates/covariates.csv`.

5. **Index procedure** (`Index_Procedure`) — replace `REPLACE_ME` with the
   SNOMED-CT procedure code. Must match `study_params.yaml > target > index_event
   > ancestor_concept_ids`. Run:
   ```
   Rscript scripts/concept_lookup.R "<procedure name>" Procedure
   ```

6. **Outcome** (`Outcome_Onset`) — replace `REPLACE_ME` with the SNOMED-CT
   concept code for the study outcome. Must match `study_params.yaml > outcome >
   ancestor_concept_ids`. Run:
   ```
   Rscript scripts/concept_lookup.R "<outcome name>" Condition
   ```

7. **Outcome incidence** (`Outcome_Assessment`) — set the `Outcome_Onset`
   distribution to the expected incidence in your target population (0.0–1.0).

8. **Oversampling** (`Treatment_Strategy`) — tune `Non_Exposed_Path_End`
   distribution. Default 10% non-exposed / 90% target-exposed is aggressive
   enrichment. Document the real-world proportion in remarks for calibration.

## Updating the module

After editing `study_template.json`:

1. Run `workflow/03_generate_synthea_module_artifacts.R` to regenerate the diagram:
   ```bash
   Rscript workflow/03_generate_synthea_module_artifacts.R
   ```
2. Open `synthea/modules/study_template.diagram.html` in a browser for SME review.
3. Repeat until the SME signs off on clinical codes, prevalences, and timing.
4. Run `workflow/04_generate_synthea_csv.sh` to generate synthetic CSV data.
5. Verify concept alignment:
   ```bash
   grep -c "REPLACE_ME" synthea/modules/study_template.json
   ```
   This should return 0 before proceeding to Step 4.
