The four categories are EMERGENT, not assigned. Each patient walks 12 monthly slices; a re-amputation hazard fires, then a death hazard, and death ends the timeline — so competing risks and censoring come for free. Emergent column is a 200,000-patient Monte-Carlo walk of this graph.

Why the multiplier exists: MoRe's published split is not consistent with independent hazards. Tuning to hit both marginals exactly gives D/R = 3.3%, but MoRe reports 5.1% — so re-amputation and death are positively dependent, which is clinically expected. The 1.85× elevation is what reproduces that cell.

The red nodes are the point. MoRe's level and re-amputation logic cannot be expressed in circe, so pad-bka-aka-prog must hand-author its cohort SQL. The negative controls exist so a wrong implementation fails instead of passing: revisions inside the guillotine exclusion window (days 1–21, with 21/22 as the boundary pair), contralateral amputations, and toe/ray amputations — the last because minor_amputation contains toe and ray, so SQL built from that broad set rather than forefoot_midfoot_amputation will over-count.
