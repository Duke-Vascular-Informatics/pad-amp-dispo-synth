Guillotines occur only at TT and TF — MoRe says so explicitly, so TM is always definitive. That is why the guillotine share is 13.3% of all patients rather than 20%.

The closure defines the index level. MoRe searches forward three weeks “to classify the incident level” — a guillotine TT closed at TF is an incident TF. Three branches, and branch (b) is the sharpest test in the dataset: the same amputation code at day 20 is part of the index event, at day 25 it is an outcome. Nothing else tests the two-window rule.

⛔ Blocker: the guillotine codes are CPT4-only (27882 → OMOP 2105448, 27592 → OMOP 2105211). No SNOMED guillotine-amputation concept exists. This pipeline has only ever emitted SNOMED-CT/RxNorm/LOINC, so confirm the ETL carries CPT4 before trusting any guillotine output.
